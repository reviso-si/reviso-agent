# Host MCP configs

These kits reuse the existing Reviso hosted `/mcp` endpoint and the existing
CLI stdio bridge. None of them introduces a parallel MCP server or business
model.

- [Claude Code](claude-code.md)
- [Codex](codex.md)
- [Cursor](cursor.md)
- [VS Code](vscode.md)
- [OpenClaw](openclaw.md)

Only the listed host capabilities are claimed. Gemini, Windsurf, OpenHands,
Aider, Cline and Roo are capability-matrix entries, not verified adapters.
