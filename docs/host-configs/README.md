# Host MCP configs

These kits connect to the hosted Reviso `/mcp` endpoint. Self-hosted installations
can also use the [stdio bridge supplied with the backend](../../references/mcp-setup.md).

- [Claude Code](claude-code.md)
- [Codex](codex.md)
- [Cursor](cursor.md)
- [VS Code](vscode.md)
- [OpenClaw](openclaw.md)

Only the listed host capabilities are claimed. Gemini, Windsurf, OpenHands,
Aider, Cline and Roo are capability-matrix entries, not verified adapters.
